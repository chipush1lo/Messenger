# Клієнт-серверний месенджер (ICQ Clone)

Це навчальний проект клієнт-серверного месенджера, написаний на мові **Java** з використанням **JavaFX** для графічного інтерфейсу та **SQLite / Hibernate** для бази даних.

## Можливості програми
- **Реєстрація та авторизація**: Базова ідентифікація за ім'ям (без паролів для спрощення).
- **Глобальний чат**: Спілкування з усіма учасниками мережі одночасно в кімнаті "Global Chat".
- **Приватні повідомлення**: Можливість писати користувачеві особисто.
- **Історія повідомлень**: При підключенні автоматично підвантажується історія всіх ваших чатів, навіть якщо співрозмовник зараз не в мережі.
- **Відповідь на повідомлення**: Можливість відповідати на конкретне повідомлення (клік ПКМ -> Відповісти) з візуальним цитуванням.
- **Видалення повідомлень**: Можливість видаляти свої повідомлення (ПКМ -> Видалити). Повідомлення зникає одразу у всіх співрозмовників та видаляється з бази.
- **Передача файлів**: Можливість прикріплювати та надсилати файли розміром до 5 МБ через кнопку-скріпку.

## Технології
- **Java 17** (або новіша версія)
- **JavaFX 17** (для UI)
- **Maven** (для збірки та управління залежностями)
- **SQLite** (локальна база даних на сервері `icq_messages.db`)
- **Hibernate ORM 6.4.4** (для роботи з базою даних через Entity)
- **Jackson (jackson-dataformat-xml)** (для серіалізації/десеріалізації об'єктів `Message` у форматі XML при передачі через сокети)

## Архітектура
- `org.example.client` - Логіка клієнта (GUI на JavaFX, мережевий клієнт). Запускається через `ClientLauncher`.
- `org.example.server` - Логіка сервера (обробка підключень `ClientHandler`, GUI сервера, робота з базою `DatabaseManager`). Запускається через `ServerLauncher`.
- `org.example.protocol` - Спільні класи для обміну даними (`Message`, `MessageType`, та `XmlProtocolHelper`).

## Як запустити
1. Переконайтеся, що у вас встановлена **Java 17+** та **Maven**.
2. В IntelliJ IDEA відкрийте проект і дочекайтеся завантаження залежностей (`Maven -> Reload project`).
3. Запустіть сервер через клас `org.example.server.ServerLauncher` (Run).
4. Запустіть клієнт через клас `org.example.client.ClientLauncher` (Run). Клієнтів можна запускати кілька разів.
